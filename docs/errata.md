# 勘误与问题反馈

阅读中发现解释不清、技术错误、练习结果不符或页面问题，可以用下面的工具整理报告。尽量指出章节、小节和材料版本，并区分实际执行结果与纸面推演。

**目前没有对外在线收件地址。** 本页支持在浏览器本地准备、复制和下载报告；没有仓库权限的读者可把文本交给向自己提供教材的维护者。有权限的协作者可以打开预填的私有 GitHub Issue 草稿，再自行确认提交。复制、下载或打开草稿均不表示反馈已经收到。

## 在源码或实验包中阅读

上面的交互工具只在阅读站运行。直接阅读 Markdown 或使用固定版本实验包时，可复制这个文本模板：

```text
页面 / 小节：
材料版本 / 完整 commit：
问题类型：文字或解释 / 技术准确性 / 练习或参考答案 / 阅读功能或材料获取
我的理解 / 期望结果：
实际文字 / 命令与返回：
最小复现 / 可检查依据：
环境与影响范围：
```

实验包的完整 commit 和文件校验记录见包内清单，使用方法见[固定版本实验包](experiment-package.md)。不确定版本时写“未知”，不要猜一个通过过的版本。

## 如何转交

- 有仓库权限：[建立私有 Issue](https://github.com/zyg0733/agent-systems-engineering/issues/new)。按真实结果填写，不要覆盖或改写失败记录。
- 没有仓库权限：下载或复制报告，交给提供教材的人。当前没有自助授权或公共表单，详见[材料获取与权限](material-access.md)。

先删去凭据、个人文件和无关日志，只附最小必要输出。请勿把未知结果当作安全重试的依据；有关执行故障可先查[恢复运行手册](recovery-runbook.md)。

## 勘误如何更新

维护者复核报告后，在相应正文或实验中修订，并通过私有 Issues 或原转交渠道说明结果。修订记录绑定实际提交；历史冻结产物、原始失败和旧版验收不随正文修订改写。没有公开承诺固定回复时间。
