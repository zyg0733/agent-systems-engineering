# 材料获取、源码权限与反馈

本书目前提供 30 章草稿、实验讲解和教师参考。**当前只有本地阅读站和授权用户可取得的私有预览，尚无公开网站或公开实验下载地址。** 本页说明材料的边界，不授予仓库权限，也不表示已经发布。

## 先判断需要哪种材料

| 你想做什么 | 所需材料与权限 | 现在怎么继续 |
| --- | --- | --- |
| 阅读概念、看图、预测和比较参考推理 | 阅读页本身；不需要模型账号或本地运行时 | 从[完整阅读路线](../book/reading-route.md)开始 |
| 运行本项目实验、修改实现或执行测试 | 实验源码及 fixture、固定工具链、自己的实验资源 | 克隆获准访问的仓库，或取得维护者交付的[固定版本实验包](experiment-package.md)并先验包；Linux 用[core 入门路线](linux-core-start.md) |
| 打开正文的源码、测试或配置引用 | 私有 GitHub 仓库的读取权限 | 没有权限时先读正文中的解释、例子与一手资料；向提供本教材的维护者申请所需源码 |
| 构建自己的阅读站 | 完整 Git 克隆及 Node.js 24 | 按[阅读站维护说明](reading-site.md)操作；实验导出包不包含 Node 站点工具链 |
| 复核作者历史原始结果 | 具体源码身份和经过检查的证据集合 | 按[证据说明](evidence-guide.md)约定所需范围；旧作者工作区的 `artifacts/` 不随克隆取得 |

网页不能代替本地 BEAM、PostgreSQL 或隔离后端。阅读页可用，也不意味着其中的私有源码链接对所有人开放。GitHub 的 404 可能是缺少仓库权限；不要据此自行改用未知仓库或执行来源不明的脚本。

## 已有源码权限

仓库为 [zyg0733/agent-systems-engineering](https://github.com/zyg0733/agent-systems-engineering)（需权限）。使用你已经获准的 GitHub 身份克隆，确认当前检出的 commit，再按 README 或对应手册操作。实验前在自己的副本和专用资源中进行，输出使用新目录。

后续修订以所检出版本为准。源码准备检查、每次 Actions、历史冻结候选和教材编辑记录分别绑定各自身份；不以 `main` 将来变化后的结果替换旧验证。当前书稿仍为草稿，软件版本仍为 `0.1.0-dev`。

授权用户也可以在对应提交的 `Reading site` Actions 运行中下载独立实验包 artifact。它包含固定提交的源码 ZIP、清单与校验值，和静态网站预览分别保存；具体命名、保留期、验证及解包步骤见[实验包说明](experiment-package.md)。Artifacts 仍需仓库权限，不是公共下载地址。

## 没有源码权限

当前没有自助开通入口，也没有公开的实验包链接。请向**提供本教材的维护者**转交下面的申请信息，由维护者决定邀请访问或单独交付经过检查的固定版本实验包。不要在申请中发送 token、密码、数据库连接串或个人文件。

```text
希望取得的材料：例如 L01 内存练习 / Linux core / 某章引用源码
阅读页与版本：页面地址、已知 commit 或版本；不知道就填写“未知”
环境：操作系统与架构，是否已有固定版本的 Elixir/OTP/PostgreSQL
用途与范围：阅读核对 / 个人实验 / 授课
```

提交申请不代表已获准访问。在取得可信材料前，可以继续概念阅读、纸面预测和设计推演；把“尚未执行”留在记录中，不复制别人的输出充当自己的实验结果。

日后若只开放阅读站，首页及动手入口会继续标明实验材料的访问条件；若希望任何读者都能复现，则需另行提供无需私有权限的固定版本源码、fixture、许可和校验清单，并实际核对未登录读者的取得路线。当前没有执行这些公开操作。

## 反馈与勘误

使用[勘误报告工具](errata.md)填写页面、版本和问题，检查后复制或下载纯文本报告。工具不会自动发送内容；有权限的协作者可打开预填私有 Issue 草稿，再在 GitHub 自行提交。没有仓库权限时，按原材料提供渠道转交文本。当前尚未指定公共邮箱或表单。

反馈请包含材料位置、版本、问题和可检查的依据：

```text
页面 / 小节：
源码 commit 或材料版本：
我理解的说法 / 期望结果：
实际文字 / 命令与返回：
最小复现或对应源码位置：
影响范围：只影响解释 / 阻塞练习 / 可能改变执行目标
```

有仓库权限的协作者可到[私有 Issues](https://github.com/zyg0733/agent-systems-engineering/issues)反馈；编辑原稿可从[私有仓库](https://github.com/zyg0733/agent-systems-engineering)对应文件进入。没有权限的读者请把模板交给提供教材的维护者；目前没有对外提交表单，也不要求先注册新的学习平台账号。

先删除凭据与无关私人内容，再提供最小必要输出。遇到命令结果不同，保留原始失败和自己的新目录；不要改写历史报告、覆盖旧输出或放宽断言来获得通过。
