# ADR 0021：冻结六章试读与分开的复现验收

状态：W22 实现。原计划本周不扩展业务运行时；用户确认先完成试读包与技术验收，真人记录后补。本 ADR 不把未取得的外部反馈写成完成。

## 决定

以原计划 ch02/ch05/ch08/ch14/ch16/ch20 为固定六章，按已交付的 L01—L20 映射实际步骤。新增 ReaderStudy 与 Reproduction 是可信宿主的文件准备/验收工具，不进入模型工具目录，不启动应用或执行读者反馈，不修改业务数据库。

Reproduction 按 allowlist 导出自含源码和文档，排除安装、依赖、build、PGDATA 和旧产物；保存 SHA-256、字节数、模式与目录。新目标、源前后扫描、文件类型、总量和实体路径检查共同保证可核对的导出；同一 private host 目录仍要求没有恶意并发写者。固定 plan 仅输出数据，实际执行由受信宿主完成。

可选择复用声明的安装 archive/Hex/Rebar3 构建工具及包缓存，逐项记录 provenance/hash；不复制已安装 runtime、deps/_build 或旧数据库。技术演练重新安装、编译 PostgreSQL 与依赖、创建新 cluster，使用独立路径和端口并清除继承环境。保证范围是同宿主新环境，不是冷网络安装或异机认证。

ReaderStudy 的 protocol 绑定完整源码 manifest 和六章、实验、指南、手册 assets，并与冻结 suite 一致。反馈为有界 inert JSON，严格字段、匿名 ID、UTC 时间、完整章节、固定 command ID、独立性声明和明确结果；未知/缺失/冲突/模板/代理记录拒绝。它是宿主提供的自报，不是认证，hash 也不是签名。

技术和外部 gate 分开：技术日志声明全部通过后可记 technical passed；外部需3–5份完整独立真人自报、至少一份新工作区主实验通过、没有未解决 blocker。合成测试仅在临时目录/内存生成并清理；正式包初始0人，未满足外部 gate 时 P5 仍 false。

## 验证与代价

测试覆盖导出与 cache 同一性、旧目录/链接/实体别名/漂移/超量拒绝，以及反馈/协议/报告完整性、惯性文本、不同 gate、大小边界和缺失事实。每个主实验沿用原权限、已扣预算、absolute deadline、unknown、工具回执和审批/fencing合同；完整回归另外执行。

该方案增加宿主准备和显式证据管理；它不自动邀请读者，不发送消息，不从自报真假推导认证结论，也不将本轮完整演练扩大为生产部署保证。未取得的真人反馈保留明确待验收项。配套 [L21](../../labs/L21-reader-study-and-clean-reproduction.md) 与[验收](../validation-week22.md)。
