# ADR 0025：显式环境执行与有界证据采集

状态：W26 实现。承接 [ADR 0024](0024-versioned-release-assessment.md)、[L25](../../labs/L25-cross-environment-validation.md)与[跨环境操作手册](../cross-environment-validation.md)。实际机器、命令与结果另见 [W26 验收](../validation-week26.md)。

## 背景

W25 已有固定发行政策和只读环境证据验证，但没有可交接的执行、来源记录与采集流程。W22 的同宿主 warm-cache 复现不能证明新主机冷安装；Linux 自动排除 macOS Seatbelt 测试，也不能证明完整 Linux 隔离。需要让缺口可执行、结果可核对，同时保留原候选与原门槛。

## 决定

将可信宿主的执行器与惰性文件采集器分开。执行器只执行受版本管理的固定命令计划，使用显式冻结源码的独立工作副本，记录实际平台、工具、缓存、安装输入、命令退出码与原始日志。采集器不执行记录中的 argv，也不启动业务应用或连接数据库；它检查绑定、模式、路径、hash 和容量后生成独立证据目录，交给既有 `ReleaseAssessment` 只读重算。

控制工具的源码与被验证候选的源码分别记录。rc.1 的工作副本保留 W24 冻结源码，不向其中添加 W26 CLI 来假装源码未变。执行前后都核对冻结文件；安装、编译和结果只进入允许的派生目录。原 W22 包、W24 候选、归档和 W25 试读包不被写入。

冷安装要求实际新 macOS 主机及未复用的 runtime、依赖和数据库；新目录不等于新主机。安装输入记录来源和实际内容摘要，无法认证来源时明确写为宿主自报，不将 SHA、版本 URL 或版本 tag 当作发布者签名。已有安装缓存只能按 warm-cache 执行记录，不补造下载或冷安装事实。

Linux 核心适用流程与完整门槛分别报告。核心回归中排除 `:seatbelt` 是现有平台边界；适用通过、排除和明确拒绝项分别保存。完整 Linux gate 仍要求无平台排除、全部隔离探针和 12×20 冻结矩阵；没有新增 Linux 隔离后端就不能将核心结果提升为 full。

执行器使用全新自有 PostgreSQL 集群、明确回环端口和新实验库，清除继承数据库路由。清理必须重新核对本轮 PGDATA、PID 和端口绑定，只停止确属本轮的资源并确认端口释放；不停止共享 55432，不清空旧 dev/test。中断、超时或证据损坏保留现场，不能用手改成功状态或放宽权限绕过。

## 后果与限制

本地自动化可以验证拒绝路径、执行流程和文件一致性，不能认证真人、独立机器或上游来源。未取得的真实冷主机/Linux 材料继续 pending；采集成功及 CLI 退出 0 不等于发行 gate 通过。没有自动批准、tag、上传或发布。

本周不改变 Run、Event、调度、工具或恢复合同。权限、已用预算、原绝对 deadline、operation ID、unknown/reconcile、审批产物 hash、lease/heartbeat/fencing 与原 migration/依赖锁保持。执行器故障不是业务恢复授权；业务事故仍按[恢复手册](../recovery-runbook.md)处理。
